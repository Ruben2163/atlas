# Atlas 
Displays system stats on a webpage using psutil then hosts the data on a FastAPI service to be requested by the website

## Data

| Sensor |  Working |   
|-----------|---|
| CPU Freq  |  ✅|  
|      CPU Temp     |  ✅ | 
|      Ram Usage     |  ✅ |   
|      Disk Usage     |  ✅ |   
|      Fan RPM     | ✅  |   
|      Network Data    |  ❌ |
